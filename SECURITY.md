# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/koorchik/rust-livr-axum/security/advisories/new), not in public issues.

Examples: a panic, a stack overflow, or unbounded memory or CPU use caused by a request; a request that reaches a handler although the rules reject it; an error response that leaks details of the server.

You will get an answer within a week. Fixes are released as patch versions of the latest minor version.

A vulnerability of the validation itself belongs to [livr](https://github.com/koorchik/rust-livr/security/advisories/new).
